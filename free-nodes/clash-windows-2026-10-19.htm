为什么我们需要科学上网？

1. 访问受限资源

许多国际网站（如Google Scholar、YouTube、Netflix等）在国内无法直接访问，而科学上网能帮助我们获取这些宝贵的资源，无论是学术研究、商业资讯还是娱乐内容。

2. 保护隐私安全

普通网络连接容易受到监控和数据泄露的威胁，而科学上网工具（如VPN）通过加密技术保护数据传输，防止个人信息被窃取。

3. 绕过地理封锁

部分在线服务（如某些新闻网站或流媒体平台）会根据用户IP地址限制访问权限，科学上网可以模拟其他地区的IP，突破地域限制。

重庆科学上网的常用方式

1. VPN（虚拟专用网络）

优点：
- 连接稳定，速度较快
- 提供全面的加密保护
- 支持多设备同时使用

适用场景：
- 需要稳定访问国际网站（如远程办公、在线会议）
- 对隐私保护要求较高的用户

使用方法：
1. 选择可靠的VPN服务商（如ExpressVPN、NordVPN等）。
2. 下载并安装官方客户端。
3. 登录账户，选择目标服务器（如美国、日本等）。
4. 连接成功后即可自由访问全球网络。

2. Shadowsocks（SS）

优点：
- 轻量级，占用资源少
- 适合访问被屏蔽的网站
- 配置灵活，可自建服务器

适用场景：
- 需要高效访问特定网站（如Google、Twitter）
- 对速度要求较高的用户

使用方法：
1. 下载Shadowsocks客户端（如Windows版、Android版）。
2. 获取服务器配置信息（地址、端口、密码等）。
3. 在客户端填入参数并连接。
4. 测试是否能正常访问目标网站。

3. V2Ray（Vmess协议）

优点：
- 抗封锁能力强
- 支持多种传输协议（如WebSocket、TCP）
- 适合高级用户自定义配置

适用场景：
- 网络环境复杂（如企业网络、校园网）
- 需要更高匿名性的用户

使用方法：
1. 下载V2Ray客户端（如V2RayN、Qv2ray）。
2. 导入服务器配置文件（通常为JSON格式）。
3. 启动代理并测试连接。

FAQ

Surfboard 如何结合规则实现智能节点切换？
Surfboard 可根据规则文件和策略组自动选择延迟低、稳定性高的节点处理流量。不同应用流量可分配不同节点，优化访问速度和稳定性，减少手动切换节点的操作。
Matsuri 可以用于 Android 吗？
Matsuri 主要针对桌面平台开发，目前并未推出 Android 版本。但可使用其配置文件在兼容的客户端（如 Nekobox 或 Clash Android）中加载以获得类似体验。
Trojan 的伪装域名选择有哪些原则？
伪装域名必须是真实可访问网站，并且证书有效。这样可以让 Trojan 流量看起来像普通 HTTPS 请求，减少被封锁或 DPI 检测风险，确保节点安全和可用性。
如何在路由器上使用 PassWall2 为不同设备设置不同策略？
在 PassWall2 的规则或策略组中为固定 IP 或 MAC 地址创建特定路由条目，将其映射到不同的策略组（如工作机走直连、游戏机走低延迟节点），并保存规则后重载以生效。
Trojan 协议的安全性如何？
Trojan 使用与 HTTPS 类似的 TLS 加密通道，使其数据流难以与普通网页访问区分。它兼具隐蔽性与安全性，几乎无法被防火墙检测。Trojan 协议的主要优势在于稳定、安全、兼容性强，因此广受高级用户青睐。
Nekobox 可以与 Shadowsocks 等客户端同时使用吗？
可以。Nekobox 配置独立，与 Shadowsocks、Clash 等客户端互不干扰。用户可根据需要通过策略组选择节点，实现灵活的网络管理和分流策略。
WinXray 是否支持订阅自动更新？
是的，WinXray 支持定时订阅更新。用户可在设置中开启自动更新周期（如每天或每小时），程序会自动下载新节点并替换旧配置，确保使用最新的线路资源。
Matsuri 的延迟测试准确吗？
Matsuri 的延迟测试使用 ICMP 与 TCP 双重检测方式，可较准确反映节点实际响应时间。不过受网络波动影响，建议多次测试并结合速度测试结果综合判断。
WinXray 的主要特点是什么？
WinXray 是一款基于 V2Ray 核心的 Windows 客户端，界面直观，支持 VMess、VLess、Trojan、Shadowsocks 等多协议。它提供一键导入订阅、节点测速、自动分流等功能，是适合初学者和进阶用户的图形化代理工具。
Mellow 的 TUN 模式是否支持全局游戏加速？
支持。TUN 模式拦截系统 IP 层流量，实现全局代理，确保游戏和其他应用的 UDP/TCP 流量都走代理节点，从而降低延迟，提高游戏体验。
